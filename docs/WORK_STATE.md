A parent potentially mutating tool marks outstanding evidence as possibly stale. Source relevance must be assessed before integration.
- Clean meaningful assistant text before generated truncation notices can count as an answer. Blank/control-only finals must not manufacture completion or erase useful retained partial evidence.
- POSIX uses a local JS lifecycle supervisor with private IPC readiness/start and owner-lifetime channels; the target inherits stdio, not the lifetime channel. Owner disconnect kills the target process group; normal cancellation retains TERM/KILL escalation and descendant cleanup. This is user-space control, not atomic containment; simultaneous owner/supervisor loss, escaped process groups and hostile trusted code remain outside guarantees. Reuse the owner's runtime, without installing Rust or dependencies for POSIX.
- Windows retains the explicitly built Rust Job Object controller in `native/windows-job/`, with locked dependencies, restricted handle inheritance, atomic suspended assignment and parent-death monitoring. Missing/failed containment fails closed; delegation never builds it or falls back to taskkill. Native Windows cancellation is not graceful POSIX signaling.

Public event order establishes work before result delivery, not actual overlapping execution, speed, private model rationale or total cost.

MCP was disabled only for the experiment invocations; default profile tools and production extensions remained loaded.
